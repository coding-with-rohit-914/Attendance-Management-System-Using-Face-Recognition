# Attendance-Management-System-Using-Face-Recognition
A modern, automated, and contactless attendance system that leverages the power of face recognition technology. This system replaces traditional manual attendance methods, making the process faster, more secure, and efficient. It captures employee or student images via a webcam, identifies them in real-time, and logs their attendance with a timestamp in a database.

✨ Features
User-Friendly Interface: Simple GUI for easy interaction.

Face Registration: Easily register new users by capturing their face images and storing their encodings.

Real-Time Recognition: Detect and recognize faces in real-time using a webcam.

Automated Logging: Automatically marks attendance with date and time in a CSV file or database.

Duplicate Prevention: Prevents logging the same person multiple times within a configurable time window (e.g., same day).

Cross-Platform: Works on Windows, macOS, and Linux.

Export Data: Ability to export attendance records for further analysis.
